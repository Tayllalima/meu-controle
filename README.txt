MEU CONTROLE V2
================

Esta V2 inclui:
- dashboard mensal
- gastos e entradas
- categorias personalizadas
- parcelamentos de até 24x
- orçamento por categoria
- análise mensal
- próximas parcelas
- PWA para instalação no celular
- armazenamento local como modo de funcionamento imediato

SINCRONIZAÇÃO
-------------
A V2 já vem acompanhada de schema_supabase.sql para a próxima etapa de sincronização.
Para ativar a nuvem ainda são necessários:
1. criar um projeto Supabase;
2. executar o schema SQL;
3. conectar a URL e chave pública do projeto;
4. implementar login e sincronização.

IMPORTANTE
----------
Nesta entrega, o app continua funcionando localmente. O banco remoto não é ativado automaticamente porque seria necessário inserir as credenciais do seu projeto.
